Antes de conectar:
  1. Crie um projeto grátis em supabase.com (se ainda não tiver um).
  2. Abra o SQL Editor do projeto e rode o script supabase-schema.sql que veio junto com este arquivo.
  3. Vá em Project Settings → API e copie a Project URL e a chave anon public.
  4. Cole os dois campos abaixo e clique em Conectar.
